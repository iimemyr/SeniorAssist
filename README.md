
# SeniorAssist

A Web-Based Senior Citizen Assistance and Community Service Coordination System with AI-Assisted Information Support.

## Project Overview

SeniorAssist is an academic project developed for IT415: Application Development and Emerging Technologies at Davao del Norte State College.

The system aims to organize senior citizen service information and assistance requests through a web-based interface.

## Project Status

Currently under development.

## Getting Started

Install the project dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Technology Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Git and GitHub
- Vercel (planned deployment)
